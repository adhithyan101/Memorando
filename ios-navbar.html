Welcome

This navbar uses backdrop-filter: blur(40px) saturate(180%) with a semi-transparent background — the same technique iOS uses for its translucent navigation bars. The result is a crisp, depth-layered glass effect that adapts to whatever is behind it.

Glassy details

• 28px border radius for pill-like softness
• Subtle inset highlight for physical depth
• Active indicator pill under current tab
• Hover/focus states on interactive elements
• Dark mode support (toggle below)
• Icon-only action buttons with circular hit areas

Tailwind + custom CSS

Uses Tailwind via CDN for utility classes, plus a small custom stylesheet for the glass properties ( backdrop-filter, border, box-shadow ). The navbar is fixed at the top, centered, and capped at 420px wide for a phone-like frame.
